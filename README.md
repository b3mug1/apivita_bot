# Apivita Telegram Bot

Бот для оформления заказов мёда и продуктов пчеловодства **АпивитА**.

## Стек технологий

- **Python 3.11+**
- **Aiogram 3.x** — асинхронный Telegram Bot API фреймворк
- **PostgreSQL** — база данных
- **SQLAlchemy (asyncpg)** — ORM
- **Alembic** — миграции БД
- **Loguru** — логирование

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <repo>
cd apivita_bot
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

```bash
copy .env.example .env
```

Отредактируйте `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
DB_HOST=localhost
DB_PORT=5432
DB_NAME=apivita_db
DB_USER=apivita_user
DB_PASSWORD=ваш_пароль
```

### 3. Настройка PostgreSQL

```sql
-- Подключиться к psql как postgres
CREATE DATABASE apivita_db;
CREATE USER apivita_user WITH PASSWORD 'ваш_пароль';
GRANT ALL PRIVILEGES ON DATABASE apivita_db TO apivita_user;
```

Применить схему:

```bash
psql -U apivita_user -d apivita_db -f migrations/init.sql
```

### 4. Запуск бота

```bash
python main.py
```

## Регистрация бота через BotFather

1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Введите **название**: `АпивитА — Натуральный мёд`
4. Введите **username**: `apivita_order_bot` (или другой свободный)
5. Сохраните полученный **токен** в `.env`

## Функционал бота

### Telegram Mini App

Веб-магазин доступен из Telegram через кнопку меню бота: каталог, корзина и оформление заказа. Mini App использует те же товары и PostgreSQL, что и бот. Для локального запуска задайте `WEBAPP_URL` адресом HTTPS-публикации приложения; приложение проверяет подпись `initData` Telegram и принимает запросы только от пользователей Telegram.

Для Vercel нужны внешние PostgreSQL и Redis, так как функции Vercel не хранят локальное состояние между запросами. В настройках проекта задайте `BOT_TOKEN`, `ADMIN_IDS`, `DATABASE_URL` (с пулером подключений, если доступен), `REDIS_URL`, `WEBHOOK_SECRET` и `WEBAPP_URL` (домен проекта Vercel); также задайте `VERCEL=1`. Redis используется для FSM-состояний webhook-бота. Приложение автоматически определяется Vercel по `index.py`; перед публикацией достаточно импортировать репозиторий в Vercel либо выполнить `vercel` (CLI версии 48.1.8 или новее).

После деплоя настройте webhook и кнопку Mini App командой `python scripts/configure_telegram.py`, запущенной с этими переменными окружения. В BotFather выполните `/setdomain` и укажите домен Vercel. Mini App будет открываться кнопкой «Магазин» в меню бота. Не запускайте одновременно `python main.py` и webhook для одного бота: локальный polling и production webhook взаимоисключающие.

### Заказы с сайта

На сайте корзина сохраняется в браузере, а заказ оформляется через форму с городом, адресом и телефоном. Такие заказы используют актуальные цены каталога, сохраняются в общей таблице заказов и отправляются администраторам в Telegram; покупателю не нужно открывать бота или WhatsApp. Заказы с сайта не привязаны к Telegram-аккаунту, поэтому история заказов в Mini App для них недоступна.

Для существующей базы примените миграцию до публикации сайта:

```bash
psql "$DATABASE_URL" -f migrations/20261013_guest_web_orders.sql
```

### Для пользователей:
- 📱 **Авторизация** через кнопку "Поделиться" (номер телефона)
- 🛍 **Каталог** с разделами: Мёд в пластике, Мёд в стекле, Другие продукты
- 🔎 Каталог загружает товары порциями; нажатие на товар открывает подробную карточку
- 🎨 В Telegram-магазине светлый или тёмный фон автоматически такой же, как тема Telegram. Отдельного переключателя в магазине нет.
- 🛒 **Корзина** с редактированием и подсчётом итога
- 📦 **История заказов** со статусами
- 🚚 **Оформление заказа**: город → адрес → комментарий → подтверждение
- ℹ️ **О нас** и информация о доставке

### Для администраторов (`/admin`):
- 📦 Просмотр всех заказов
- 🔄 Изменение статусов заказов
- 📣 Рассылки (текст/фото/видео) с подтверждением
- 📊 Статистика (пользователи, заказы, выручка)

## Мультиязычность

Все тексты вынесены в `locales/ru/messages.py`. Для добавления нового языка:
1. Создайте `locales/kz/messages.py` с переводами
2. Передайте `lang=user.lang` в функции клавиатур и сообщений
